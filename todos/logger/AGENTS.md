# Reading instructions

Repository [AGENTS.md](../../AGENTS.md) and [testing policy](../../docs/testing.md) still apply.

1. Read [README.md](README.md) for scope and navigation.
2. Read [roadmap.md](roadmap.md), the **only owner of current stage/task statuses and the next action**. Locate the numbered stage heading and its selected task; do not substitute a concept index for execution order or skip an incomplete stage without recorded owner approval.
3. Read [knowledge-base.md](knowledge-base.md), [dependencies.md](dependencies.md), and the concept specification linked by the selected task.
4. Before designing or evaluating tests, follow [quality-and-acceptance.md](quality-and-acceptance.md).
5. Check [decisions-and-gaps.md](decisions-and-gaps.md) before starting dependent work. Do not implement blocked tasks by guessing an answer.

`logger.md` is a frozen historical input, not an execution plan. Do not routinely load it, update its old statuses, or take its superseded instructions as current. Source links are provided for provenance and audits only.

Update execution progress only in `roadmap.md`; update specifications only when a contract changes. Do not start implementation merely because this documentation package exists.
