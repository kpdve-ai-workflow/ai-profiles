ai-profiles — zarządzanie profilami

TWORZENIE PROFILU
  make create PROFILE=NAZWA
    Tworzy profil 1.0.0 z pustym MCP i pustym wyborem skilli. Nie nadpisuje plików.
    Opcjonalny opis: DESCRIPTION="Opis profilu"

PRACA Z PROJEKTEM
  make install CLIENT=KLIENT PROFILE=NAZWA PROJECT=SCIEZKA_DO_PROJEKTU
    Instaluje profil tylko dla wybranego klienta (nie aplikację klienta).
  make install-opencode / install-claude / install-codex PROFILE=NAZWA PROJECT=SCIEZKA
    Aliasy install z odpowiednim CLIENT; sprzeczne CLIENT jest błędem.
  make switch CLIENT=KLIENT PROFILE=NAZWA PROJECT=SCIEZKA_DO_PROJEKTU
    Zmienia zainstalowany profil na inny.
  make status PROJECT=SCIEZKA_DO_PROJEKTU
    Pokazuje wszystkie integracje; opcjonalne CLIENT ogranicza wynik.
  make update CLIENT=KLIENT PROJECT=SCIEZKA_DO_PROJEKTU
    Aktualizuje profil z lokalnych źródeł, bez pobierania zmian z sieci.
  make pull-update CLIENT=KLIENT PROJECT=SCIEZKA_DO_PROJEKTU
    Pobiera źródła przez git pull --ff-only, potem aktualizuje profil.
  make uninstall CLIENT=KLIENT PROJECT=SCIEZKA_DO_PROJEKTU
    Usuwa profil, zachowując własne pliki i ustawienia użytkownika.

UTRZYMANIE REPOZYTORIUM
  make rename PROFILE=STARA_NAZWA NEW_NAME=NOWA_NAZWA
    Zmienia katalog i name w profile.json wyłącznie w ai-profiles.
    Nie aktualizuje zainstalowanych projektów ani wersji profilu.
  make bump PROFILE=NAZWA
    Zwiększa wersję profilu. Opcjonalnie: PART=patch|minor|major (domyślnie patch).
  make validate
    Sprawdza wszystkie profile, skille i konfigurację MCP.
  make validate PROFILE=NAZWA
    Sprawdza wybrany profil, jego wybrane skille i wpisy w mcp/example.json.
    Cały rejestr MCP i nadmiarowe wpisy sprawdza pełne make validate.
  make test
    Pełne testy Rust w trwałej VM Debian 13 amd64 (Incus/QEMU/KVM).
  make test-playwright
    Buduje obraz i uruchamia pełny test adaptera/Compose/Chromium w VM.
  make validate-rust-migration
    Bramka format/build/Clippy/walidacja/testy Rust w VM.
  make test-all
    Bramka walidacji, potem Playwright (bez powtarzania testów Rust).
  make test-vm-up / test-vm-stop
    Przygotowuje/wznawia lub zatrzymuje VM bez usuwania cache.
  make test-vm-sync / test-vm-reprovision
    Synchronizuje źródła lub jawnie ponawia provisioning istniejącej VM.
    Wymagania hosta i zasoby: docs/testing.md. Host testów nie wymaga
    Cargo, Node ani Dockera. Raporty: .test-vm/artifacts/.
  make help
    Pokazuje pomoc. Samo make również pokazuje pomoc.

ARGUMENTY
  CLIENT       opencode|claude|codex|all; wymagany dla operacji zmieniających instalację.
               CLI: --client KLIENT lub --client=KLIENT. Bez domyślnego klienta.
               all: install dodaje brakujących (konflikt profili blokuje zapis),
               update/switch/uninstall obejmują tylko zainstalowanych, w kolejności
               OpenCode, Claude, Codex. Brak instalacji jest błędem tych trzech operacji.
  PROFILE      Wymagany tam, gdzie podano. Nie ma domyślnego profilu.
               create: nowa nazwa, małe litery/cyfry i pojedyncze myślniki.
               install/switch/bump/rename/validate: nazwa istniejącego profilu.
               validate: PROFILE jest opcjonalny; bez niego sprawdza wszystko.
  PROJECT      Wymagany tam, gdzie podano: istniejący katalog poza ai-profiles.
  DESCRIPTION  Opcjonalny opis dla create; domyślnie „Profil NAZWA”.
  PART         Opcjonalny rodzaj zmiany wersji dla bump.
  NEW_NAME     Wymagana nowa nazwa dla rename: małe litery/cyfry i myślniki.
