# Common workflow

- Implement the user's requested work within its stated scope. Normal file edits,
  documentation updates, tests and shell commands do not require a separate task unlock.
- Use `make-plan` or `refine-plan` when the user requests planning or refinement;
  neither skill is a mandatory prerequisite for routine implementation.
- Preserve unrelated local changes. Ask before destructive operations or unresolved
  decisions outside the user's authorization.
- Verify changes with relevant tests and report results and remaining limitations.
